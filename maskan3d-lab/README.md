# مختبر مسكن ثلاثي الأبعاد (maskan3d-lab)

مشروع استكشافي وتجريبي لتحويل صور العقارات والشقق إلى جولات ثلاثية الأبعاد تفاعلية بتقنية الـ 3D Gaussian Splatting (3DGS)، مع مراعاة الأداء على أجهزة الجوال والمتصفحات والامتثال للتراخيص التجارية.

> **ملاحظة معمارية هامة:**
> تجنباً لاستهلاك موارد الجهاز المحلي والتعقيدات التقنية (CUDA, PyTorch, Docker, COLMAP)، يتم تنفيذ كافة مراحل المعالجة الثقيلة (Structure-from-Motion والتدريب) سحابياً عبر **Google Colab (T4 GPU)**. المجلد المحلي مخصص فقط للأكواد المرجعية، صور الاختبار، ملفات العرض، وحفظ مخرجات `.ply`.

---

## 🔄 مسار المعالجة (Pipeline)

يمر مسار العمل بالمراحل التالية بالترتيب:

```
[صور الشقة (photos)] 
        │
        ▼
[1. COLMAP] ────► تقدير مواضع الكاميرات ونقاط البداية (Camera Poses & Sparse Point Cloud)
        │
        ▼
[2. nerfstudio (splatfacto) / gsplat] ────► تدريب نموذج الـ Gaussian Splatting على Google Colab
        │
        ▼
[ملف السحابة النقطية الناتجة (.ply)]
        │
        ▼
[3. SuperSplat] ────► تنظيف المشهد (قص الشوائب، تصحيح الأفق، وتخفيف حجم الملف)
        │
        ▼
[4. GaussianSplats3D] ────► محرك وعارض الويب التفاعلي ثلاثي الأبعاد الموجه للمتصفح والجوال
```

## 📦 المستودعات المرجعية ودور كل منها (Repos Overview)

### 1. COLMAP (`repos/colmap`)
- **الدور:** تنفيذ عملية الـ Structure-from-Motion (SfM). يقوم بتحليل صور الشقة واستخراج النقاط المشتركة، وحساب وضعيات واتجاهات الكاميرات (Camera Extrinsics & Intrinsics)، وتوليد سحابة نقاط أولية (Sparse Cloud) لتغذية نموذج التدريب.
- **الترخيص:** **New BSD (3-Clause BSD)** للكود الأساسي لـ COLMAP.
- **⚠️ تنبيه الاستخدام التجاري (Commercial Warning):**
  - يحتوي كود COLMAP المدمج على مكتبة فرعية تدعى `SiftGPU` (`src/thirdparty/SiftGPU/LICENSE`) مرخصة **للأغراض التعليمية والبحثية وغير الربحية فقط** (`educational, research and non-profit purposes`).
  - **الحل للاستخدام التجاري الصارم:** يُفضل إما تشغيل COLMAP على الـ CPU القياسي، أو استخراج الميزات باستخدام بدائل مفتوحة تجارياً مثل `ALIKED` أو `SuperPoint`، أو بناء COLMAP بدون تفعيل `SiftGPU`.

## 🛠️ دليل فحص وتجهيز الصور محلياً (How to Run prepare_photos.py)

قبل رفع الصور إلى Google Colab، توفر أداة `prepare_photos.py` فحصاً محلياً سريعاً وخفيفاً للتأكد من جودة مدخلاتك وتجهيز الأرشيف تلقائياً.

### 1. تثبيت المتطلبات (Requirements)
تعتمد الأداة فقط على مكتبات بايثون خفيفة (`Pillow`, `opencv-python`, `numpy`):
```bash
cd maskan3d-lab
pip install -r requirements.txt
```

### 2. تشغيل الأداة (Execution)
ضع صور الشقة داخل مجلد `photos/` ثم شغّل:
```bash
python prepare_photos.py
```
*(ملاحظة: إذا كان مجلد `photos/` فارغاً، ستقوم الأداة تلقائياً بتوليد 5 صور اختبار هندسية وضبابية لتجربة الأداة فوراً).*

### 3. ماذا تفعل الأداة؟
- 📊 **تقرير شامل:** حساب عدد الصور، نطاق الأبعاد (Resolution Range)، وإجمالي الحجم.
- 🔍 **كشف الضبابية (Blur Detection):** حساب تباين لابلاس (Laplacian Variance) وفرز الصور من الأكثر ضبابية إلى الأكثر حدة لتنبيهك بحذف الصور المهتزة.
- 🔄 **تصحيح التدوير (EXIF Orientation Fix):** فحص علامات EXIF وإصلاح اتجاه الصور المقلوبة أو المائلة فيزيائياً لتفادي أخطاء COLMAP.
- ⚠️ **تحذير ذكي لكثافة الصور:**
  - تنبيه إذا كان العدد **أقل من 60 صورة** (لتجنب ضعف التغطية وفشل بناء المشهد).
  - تنبيه إذا كان العدد **أكثر من 250 صورة** (لتجنب استهلاك وقت طويل على معالج Colab المجاني).
- 📦 **إنشاء `photos.zip` مسطح (Flat ZIP):** تجميع الصور في ملف `photos.zip` في المسار الجذري دون أي مجلدات فرعية ليكون جاهزاً للسحب والإفلات مباشرة في Google Colab.

### 4. خيارات إضافية (CLI Options)
```bash
python prepare_photos.py --help
# تخصيص مسار الصور ومستوى حساسية الضبابية:
python prepare_photos.py --photos-dir ./photos --blur-threshold 120.0 --output-zip ./photos.zip
```
